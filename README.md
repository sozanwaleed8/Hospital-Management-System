# 🏥 Hospital Management System

A full-stack hospital management system built with PHP, MySQL, HTML, CSS, and Bootstrap.

## 🚀 Features
- User authentication (Login & Register)
- Role-based system (Doctor, Patient, Pharmacist)
- Patient management (Add, Update, Delete)
- Drug management system
- Assign medications to patients
- Secure password hashing
- Responsive UI design

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML, CSS
- Bootstrap

## 📂 How to Run
1. Import the database file `hospital.sql`
